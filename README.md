# SVG Illustration Composer · Векторный Конструктор Композиций

Веб-сервис на **Python (Django 5 + Django REST Framework)** для автоматической и полуавтоматической сборки векторных изометрических иллюстраций из библиотеки независимых SVG-компонентов.

Проект строго соблюдает ключевое ограничение: **никакой генерации растровых диффузий** — итоговая сцена состоит исключительно из оригинальных векторных объектов библиотеки из Figma, сохраняя пропорции, слои и векторную чистоту.

---

## 🚀 Быстрый старт

Проект управляется через современный пакетный менеджер `uv` (Python 3.12+):

```bash
# Клонирование / переход в директорию
cd Job_Task_3

# Запуск веб-сервиса (автоматически создаст виртуальное окружение и подтянет зависимости)
uv run python main.py
```

Сервер запустится на **http://127.0.0.1:8000/**.  
В браузере откроется полнофункциональный графический интерфейс с интерактивным холстом.

### Запуск тестов:
```bash
uv run pytest
```
*Все 9 unit-тестов проверяют целостность 40 ассетов, правило палитр, математические лейауты, NLP-матчинг и API.*

## 🏛️ Архитектура системы

### 1. Хранение SVG-элементов (`assets/`)
* **Библиотека ассетов (`assets/elements/`)**:
  Включает 10 объектов из Figma, каждый представлен в 4 вариантах (итого **40 чистых SVG файлов**):
  * **2 размера детализации**: `L` (высокая детализация) и `S` (упрощенная для малых форматов).
  * **2 состояния**: `Main` (полноцветная 3D-изометрия) и `Bg` (монохромный силуэт для создания глубины заднего плана).
  * Объекты: `book` (книга), `phone` (смартфон), `headphones` (наушники), `lamp` (лампа), `wallet` (кошелек), `puzzle` (пазлы), `coin` (монета), `folder` (папка), `pen` (ручка), `vase` (ваза с тюльпанами).
* **Словарь метаданных (`assets/library.json`)**:
  Хранит семантические теги, категории, размеры viewBox и соотношения сторон.
* **Спецификация палитр (`assets/palettes.json`)**:
  Описывает 3 базовые цветовые схемы (`purple`, `peach`, `mint`) с разделением ролей цветов фона и объектов.

### 2. Извлечение и нормализация (`LibraryService`)
* Извлекает векторное содержимое элементов без внешнего тега `<svg>`, гарантируя чистоту DOM.
* Выделяет блоки `<defs>` (клип-пути, маски) и назначает им уникальные пространства имен (`o0_`, `o1_`...), предотвращая конфликты при многократном дублировании одного и того же объекта на одном холсте.
* Сохраняет строгие пропорции ($scale_x = scale_y$).

### 3. Переиспользование и математическая компоновка (`LayoutEngine`)
Вместо ненадежной генерации координат языковой моделью, расстановку выполняет детерминированный движок:
* **Поддерживаемые форматы холста**:
  * `1200×630` (Горизонтальный баннер / соцсети)
  * `1000×1000` (Квадратный пост)
  * `800×1200` (Вертикальный постер / сториз)
* **3 архитектурных лейаута**:
  1. `under_headline`: левая треть свободна для типографики, иллюстрация сфокусирована справа.
  2. `offset`: диагональное изометрическое распределение с эффектом движения.
  3. `clustered`: центральный изометрический остров.
* **Изометрическая глубина (Z-Index)**:
  Фоновые объекты размещаются в нижних слоях, главные — в верхних. Внутри одного типа z-index динамически вычисляется по экранной координате $Y$: объекты ниже на экране визуально перекрывают объекты, стоящие дальше.

### 4. Работа с цветовой палитрой (`PaletteService`)
* **Соблюдение жесткого дизайнерского правила**:
  > *«Цвета фонов могут использоваться в объектах. Цвета для объектов не могут использоваться в фонах».*
* Сервис валидирует любую палитру (включая пользовательские) на пересечение множеств цветов фона и акцентов объектов.
* Точечная перекраска через AST/Regex без растеризации: заменяет цвета с сохранением контуров (`#181817`) и белых бликов (`#FFFFFF`).

## 💡 Реализация сценариев

### Сценарий 1: Генерация по метафоре или заголовку (ИИ)
1. Пользователь вводит текст (например: *«Дистанционное обучение и лекции»* или *«Управление семейным бюджетом»*).
2. `NlpMetaphorAgent` анализирует семантический контекст, ключевые понятия и эмоциональный окрас:
   * Выбирает 3–5 наиболее подходящих объектов.
   * Назначает роли: 1–2 цветных доминанта (`Main`) + 1–3 монохромных силуэта (`Bg`).
   * Определяет оптимальный лейаут (например, для заголовков выбирает `under_headline`).
3. Движок компоновки собирает и визуализирует сцену за **<150 миллисекунд**.

### Сценарий 2: Ручная сборка и интерактивное редактирование
1. Пользователь кликом выбирает нужные компоненты из каталога библиотеки и задает их роль (`Главный` / `Фоновый`).
2. Выбирает схему компоновки (`Собранно`, `Под заголовок`, `Со смещением`).
3. На интерактивном холсте доступно:
   * **Перемещение (Drag & Drop)** любого объекта мышью в реальном времени.
   * **Масштабирование** (сохраняя пропорции) и **вращение**.
   * **Управление слоями**: «Вперед» / «Назад».
   * **Дублирование** и **удаление**.
   * **Смена палитры** на лету одним кликом.

### Экспорт
* Кнопка **«Скачать SVG»** формирует и скачивает валидный файл `.svg`, готовый к редактированию в Figma, Adobe Illustrator или прямому встраиванию в веб.

## 🤖 Использованные AI-инструменты

1. **Google Gemini Flash / DeepMind Reasoning**:
   * Разработка архитектуры системы, проектирование математической изометрической модели и алгоритмов компоновки.
   * Анализ палитр и форматов из Figma-файла.
2. **Семантический NLP-агент (`NlpMetaphorAgent`)**:
   * Интеллектуальный анализатор метафор и заголовков с гибридным семантическим маппингом ключевых концептов на компоненты векторной библиотеки.

## 🎨 Примеры собранных композиций (`examples/`)

В папке `examples/` сохранены 3 эталонных векторных SVG-файла:

1. **`example_1_education_purple_1200x630.svg`**:
   * Метафора: *«Дистанционное образование и лекции»*
   * Формат: `1200×630`, Детализация: `L`, Палитра: `Фиолетовая`
   * Объекты: Книга (Main), Лампа (Main), Наушники (Bg), Ручка (Bg), Папка (Bg).
   * Лейаут: *Под заголовок* (свободная зона слева).

2. **`example_2_finance_peach_1000x1000.svg`**:
   * Метафора: *«Управление личными финансами и инвестиции»*
   * Формат: `1000×1000`, Детализация: `L`, Палитра: `Персиковая`
   * Объекты: Кошелек (Main), Монета (Main), Телефон (Main), Папка (Bg).
   * Лейаут: *Собранно* (центральный изометрический остров).

3. **`example_3_team_mint_800x1200.svg`**:
   * Метафора: *«Командная работа и интеграция решений»*
   * Формат: `800×1200`, Детализация: `S`, Палитра: `Мятная`
